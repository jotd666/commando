"# Commando" 
port of Commando for Amiga AGA

Requires a 1 or 2-button joystick, or the keyboard

Credits:

- jotd: reverse-engineering, 68000 transcode, graphics conversion
  sound conversion for the Amiga.
- IM76: music
- PascalDe73: icons
- Capcom: original game
- Claude A.I.: rewrite of the blitter routines for 50Hz on all machines

Instructions:

5/fire: insert coin
1/2/up/down: start game 1/2 player
arrows/joystick: move
red/ctrl: shoot
long press on red: launch grenade
blue/alt: launch grenade

Runs in NTSC but bottom of the screen is cut.
Also has a 50Hz PAL mode with 50Hz logic. Slower but smoother scrolling

Cheat keys:

F1: toggle invincibility
F2: skip level
F3: add 10000 points
